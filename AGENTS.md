# Project Guidelines & Agent Instructions

## Coding Standards
- Write clean, modular Python 3.10+ and modern ES6 JavaScript.
- Avoid unnecessary external dependencies.
- Follow PEP 8 style conventions with 4-space indentation.
- Always include descriptive docstrings and type annotations.
- Keep token usage and context windows minimal by referencing precise function and class slices.

## Build and Test Commands
- Run test suite: `pytest -v`
- Start server: `python run.py`
